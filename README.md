# Lingvoboto

A Discord Bot for Language Learning

## Purpose

This was created to create more language exposure in everyday communication. Run the bot in a Discord server with your language learning partner to get unobtrusive translations, grammar critiques, and lessons right in the chat.

## Usage

Ideally, a server should be set up exclusively for two people and the bot. At least two channels should be used: one general and one for bot log messages. Additional channels are also supported with no change to the setup process. Every message sent in the server will have a thread created on it, where the bot will share translations, grammar advice, and language feedback generated by AI. If the original message is in your native language, the bot will expose you to the translation. If the original message is in your target language, the bot will inform you of the quality of the grammar, wording, etc. Sending messages in one of these threads will send a reply to the language model, just like chatting to the model on the web. This can be used to ask follow-up questions, get clarification, or otherwise enrich the language-learning experience with actual conversational context.

## Setup

### Discord Server Setup

1. Create a Discord server and invite at least one other person. Note that the bot will be active in all channels it has access to.
2. Create a "Moderation" or "Logging" channel for the bot's console log messages to be shown in.
3. Copy the Channel ID of this moderation channel. To do this, you may need to turn on Developer Mode in the Discord client first. Save this ID somewhere.

### Discord API Key

1. Go to the Discord Developer Portal and create a new application.
2. In the application, go to "OAuth2" in the sidebar.
3. Under "OAuth2 URL Generator", select "bot". A new section will appear below called "Bot Permissions". Select the following permissions:
    - Send Messages
    - Create Public Threads
    - Create Private Threads
    - Send Messages in Threads
    - Manage Threads
    - Read Message History
4. Copy the Generated URL and paste it into a web browser to add the bot to your server.
5. Back in the Discord Developer Portal, go to "Bot" in the sidebar.
6. Turn on "Message Content Intent".
7. Here you can also set the name and profile picture for the bot.
8. Under the bot name section, there is a section called "Token". Click "Reset Token" to obtain an API key for the bot. Save this token somewhere, and never share it.

### Gemini API Key

1. Go to Google AI Studio.
2. In the bottom left, click "Get API Key".
3. Save this key somewhere, and never share it.

### Program Setup

1. Ensure you have Node 26 or later installed.
2. Clone this repo.
3. Rename the file `.env.example` to `.env` and fill in the three values saved from earlier
4. Open the file `src/settings.ts` and set the native and target language options. There are other options which can also be edited.
5. Launch the bot by running `node --env-file=.env .` in the terminal inside the repository. You should see the message "Online" in the logging Discord channel, and the bot should now show as online.
